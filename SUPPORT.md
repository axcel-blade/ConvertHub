# Getting Help

## Before asking

- Read the [README](README.md) and the [documentation](docs/).
- Check the **System & tools** page in the app to confirm FFmpeg and other
  optional tools are detected.
- Search [existing issues](https://github.com/axcel-blade/ConvertHub/issues)
  and [discussions](https://github.com/axcel-blade/ConvertHub/discussions).

## Where to ask

| Need | Where |
| --- | --- |
| Questions and how-tos | [GitHub Discussions](https://github.com/axcel-blade/ConvertHub/discussions) (Q&A) |
| Feature ideas | Discussions (Ideas) or a feature request issue |
| Bugs | [Open a bug report](https://github.com/axcel-blade/ConvertHub/issues/new/choose) |
| Security vulnerabilities | See [SECURITY.md](SECURITY.md); do not post publicly |

When reporting a problem, include your OS, ConvertHub version, the tool you
used, the input format and any error shown in the queue.

ConvertHub is maintained by volunteers; responses are best-effort.
